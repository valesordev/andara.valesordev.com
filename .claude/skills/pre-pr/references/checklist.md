# Pre-PR checklist

Every item below is a bug class that reached PR review in Valesor repos and
was caught there, by Codex or by architecture, instead of before the push.
Add a line when review catches a new class. Remove one only when a check or
test now catches that class mechanically.

## Concurrency

- [ ] Lock order is the same on every path that takes more than one lock.
- [ ] No lock released early to avoid a deadlock, if state it guarded is then
      read or written unguarded (the #127 fix that became a P1 race).
- [ ] Goroutines, channels, and timers stop on every exit path, including error
      and context cancellation.
- [ ] Shared maps, slices, and counters are guarded or confined. Run the race
      detector on the affected package (`go test -race ./pkg/...`).

## Predicates and parsing

- [ ] Matchers don't over-match: suffix vs. extension (`.aw` vs `.awx`),
      prefix vs. path segment (`foo/` vs `foobar/`), substring vs. token (the
      #132 tick-keep predicate).
- [ ] Heuristic parsing of commands, paths, or arguments is tested against
      flags, quoting, and `--` (the AW-INF-028 command-path extraction).
- [ ] Empty, nil, and zero inputs behave as specified.
- [ ] Option parsing handles unique long-option prefixes (`--har` is `--hard`
      to git and getopt) and flag precedence (`-f` wins over `-b`) (the #38
      guard bypasses).

## Checks that can pass silently

- [ ] Every check, script, or CI step fails when its target is missing, empty,
      or unreachable. "Nothing found" isn't "OK" (the world-reset Argo CD check).
- [ ] Shell scripts use `set -euo pipefail`. Pipelines don't hide a failing
      first stage.
- [ ] Assertions check values, not just the absence of an error.

## Citations

- [ ] Every metric, endpoint, flag, env var, config key, file path, make target,
      and story/ADR ID that the diff *names* exists. Grep for each one. This
      applies to stories, runbooks, and docs as well as code (the nonexistent
      metric).
- [ ] Paths named in skills, charters, and docs resolve where they run: the
      vendored `.claude/…` in a target repo, not the source tree (the #37
      checklist path).
- [ ] Every acceptance criterion in the story is met, or the gap is stated.

## Deploy surface

- [ ] Compose, k8s, and Helm manifests mount every file and volume the new
      code reads (the missing projector mounts).
- [ ] Content or schema changes are replay- and recovery-safe against existing
      data: digests, versions, migrations (AW-SRV-037's digest mismatch on
      recovery replay).
- [ ] Runbook and rollback steps are complete and in order, and each step
      names the command.

## Permission rules

- [ ] No allow rule ends in a wildcard (`:*`, ` *`) on a command with
      execution-capable flags: `make --eval`, `go -toolexec`/`-exec`,
      `gofmt -w`, kubeconfig exec plugins, `helm --post-renderer`. Allow the
      exact command instead (the #39 fragment).

## Copies and drift

- [ ] Changed files that have copies elsewhere (scaffolds, templates,
      `testdata/`, vendored `.claude/`, docs that quote the code) are updated
      too, or the copy is generated.
- [ ] Generated outputs were regenerated by their make target, not hand-edited.

## Git hygiene

- [ ] The diff contains only this branch's work: no stray staged deletions, no
      unrelated files, no debug output.
- [ ] Commits are signed and use conventional subjects.

# andara-client

Phase 2. TypeScript, WebGL. **Not started, and deliberately so.**

The client is gated on Phase 1's exit criteria — a playable world over the Text Interface and a
frozen v1 Protocol (`docs/roadmap.md`). The client carries a large art-content cost; building it
against an unstable protocol pays that cost twice.

Writing `CLT` stories before the Protocol is frozen is an anti-pattern this repo rejects
(`CLAUDE.md` §6). If you are here to start the client, check `ADR-0003` first — it is still `draft`.
